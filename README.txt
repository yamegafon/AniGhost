AniGhost — Этап 4

Что добавлено
- Интеграция с AniLiberty API: кнопка «Каталог AniLiberty» загружает свежие релизы, если API доступен из браузера.
- Страница аниме пытается найти релиз AniLiberty и отобразить список реальных эпизодов из API. При недоступности API отображается демонстрационный список с предупреждением.
- Встроенный интерфейс воспроизведения использует только URL, которые API вернул для эпизода; для HLS применяется hls.js. Доступность и разрешение встраивания зависят от внешнего провайдера.
- Настройки аккаунта открываются в отдельном окне: публичный ник, описание, аватар и фон профиля.
- Аватар и фон можно загрузить файлом. Без Supabase изображения уменьшаются и сохраняются в браузере; с Supabase — загружаются в Storage bucket profile-media.
- Карточка истории просмотренных серий остаётся в профиле. Списки аниме открываются отдельным окном через кнопку на карточке со статистикой и диаграммой.
- Добавлены avatar_url/background_url и политики Storage в supabase-schema.sql.
- Оригинальные темы и общая структура сохранены.

Как запустить локально
1. Распакуй архив.
2. Открой терминал в папке проекта и выполни: python -m http.server 8000
3. Открой http://localhost:8000. Для API лучше запускать через HTTP-сервер, а не file://.

Как подключить Supabase
1. В Supabase открой SQL Editor и выполни весь файл supabase-schema.sql (он содержит схему и миграцию Stage 4).
2. В supabase-config.js заполни url и публичный anon/publishable key. Не вставляй service_role/secret key в браузерный код.
3. В Authentication настрой Site URL и Redirect URLs для локального адреса и будущего домена.
4. Проверь, что email confirmation и OAuth настроены по желанию.

AniLiberty API
- Используемые endpoints: /anime/releases/latest?limit=30, /app/search/releases?query=..., /anime/releases/{idOrAlias}.
- API может измениться, иметь ограничения, CORS/региональные сбои или возвращать разные форматы данных. В таком случае каталог/серии покажут ошибку и демо-список.
- Встроенный HLS работает в браузерах, поддерживающих HLS нативно, либо через hls.js. Видео приходит с внешнего источника, не хранится на AniGhost. Используй API и видеопотоки только в рамках условий провайдера и применимых прав.

Важно
- Локальный профиль, включая изображения, сохраняется только в конкретном браузере и может занимать место в localStorage. Не загружай большие изображения в демо-режиме.
- В облачном режиме картинки должны быть меньше 5 MB и иметь MIME image/jpeg, image/png, image/webp или image/gif.
- Полное браузерное тестирование на реальном Supabase-проекте не выполнялось. Проверь вход, загрузку изображений, RLS и API после размещения.
